# 论断评估：能否断言"在 SαS 杂波中 GELCT 和 LS 一样会 collapse"？

> 评估对象：一个待发表的论断（可能是审稿意见或批判性论文的立论）
> 评估框架：`scientific-critical-thinking`（AERS 路由 skill）之 Claim Evaluation 流程
> 评估日期：2026-11-02
> 判据来源：本文献的式 (1)–(20)、本仓库的 GELCT 实现 `src/gelct_core.py`、
> 受控数值实验 `experiments/collapse_test.py`、`moment_growth.py`、`lct_vs_gelct.py`

---

## 0. 一句话结论

**按字面不能断言。** 该论断倒置了因果：式 (8) 的非线性变换**正是为了阻止** LS 式的崩溃而引入的，
它把"二阶矩不存在"的序列变成"任意阶矩都有限"的序列。受控实验显示，在数学上只差一个式 (8)
的两条完全相同的流程里，LS 在 α ≤ 1.2 时**从未**可靠（+10 dB 仍有 90% 的严重失效），
而 GELCT 从 −10 dB 起失效率为 **0%**。

**但论断有一个真实的内核**，见 §3.1：**去掉式 (8) 的普通线性 chirplet 变换（LCT）
确实会在 SαS 杂波中退化甚至失效**——这正是文献已明确记载的现象（Long et al., 2022）。
把 GELCT 与"未变换的 LCT"混为一谈，是这个论断最可能的来源。

---

## 1. 先把论断拆清楚（两个歧义）

### 1.1 "collapse" 至少有三种互不等价的含义

| 记法 | 含义 | 判据 | 对 GELCT 是否成立 |
|---|---|---|---|
| **C1** | 矩不存在 / MSE 无穷 | `E\|θ̂−θ\|² = ∞` | **不成立**（§2） |
| **C2** | Hurwicz–Tukey 崩溃点 = 0 | 单个任意污染样本可把估计推到任意远 | **字面上成立，但概率可忽略**（§3.2） |
| **C3** | 工程意义上的"低信噪比下估计变成垃圾" | `P(相对误差>10%)` 趋近 1 | **仅 GSNR ≤ −15 dB 成立，比 LS 低 15–20 dB 以上**（§4） |

如果在论文里用 "collapse" 而不指明是哪一种，这句断言是**不可证伪的**，因而也不可断言。

### 1.2 "LS" 指哪一个估计量

* **LS 的精确形式**（对 `(A, f0, k)` 同时最小化残差平方和）：计算上是四维非线性搜索。
* **近似最小二乘 / 周期图（de-chirp）**：固定 `k` 时 LS 的解析解就是
  `argmax_{f0} |Σ_n r[n] e^{-jπk n²/fs²} e^{-j2πf0 n/fs}|`，对 `k` 做一维搜索。
  这是文献与工程中的标准可行形式，且与精确 LS **渐近等价**。

本评估用后者作为 "LS"（`experiments/collapse_test.py`）。这个选择对本论断**有利**：
如果连"LS 的标准可行形式"都崩溃，而"只多了一步式 (8)"的 GELCT 不崩溃，那结论就只可能来自式 (8)。

## 2. 机制分析：为什么 GELCT **不可能**以 C1 的方式崩溃

式 (8) 是逐点的、**保持相位**的幅度重标定：

```
f[r] = (log_e(|r|^{1/e}) + 1)/|r| · r        =>        |f[r]| = |1 + ln|r| / e|
```

设 `X ~ S(α, 0, γ, 0)`。

* **原始信号**：`P(|X|>t) ~ C t^{-α}`，故 `E|X|^p = ∞` 对一切 `p ≥ α`。α<2 时二阶矩不存在。
* **变换后**：`P(ln|X| > s) = P(|X| > e^s) ~ C e^{-α s}` —— `ln|X|` 只有**指数尾**，
  因此 `E|ln|X||^p < ∞` 对一切 `p`。于是 **`E|f[X]|^p < ∞` 对一切 `p` 成立。**

这正好是论文 Property 1 想说的"使二阶及更高阶统计量存在"。**LS 崩塌与 GELCT 存活是同一个数学事实的两面。**

### 数值验证（`experiments/moment_growth.py`，n = 4×10⁵）

| α | 原始样本 `(1/n)Σ\|X_i\|²` | 理论 `n^{2/α−1}` | 变换后 `(1/n)Σ\|f[X_i]\|²` |
|---|---|---|---|
| 0.8 | 1.60×10⁸ | 2.53×10⁸ | **1.569** |
| 1.0 | 1.30×10⁶ | 4.00×10⁵ | **1.335** |
| 1.2 | 4.38×10³ | 5.43×10³ | **1.198** |
| 1.5 | 2.39×10² | 7.37×10¹ | **1.074** |
| 2.0 | 2.01 | 1.00 | **0.967** |

原始二阶矩按 `n^{2/α−1}` 无界增长（α<2 时），变换后对所有 α（含 α=0.8）都收敛到 O(1)。
图：`results/collapse_moments.png`。

> **补充（对本论断不利的一点，但要说清楚）**：GELCT 的映射是**对数**压缩，
> 而经典的分数低阶矩（FLOM）方法是幂律映射 `|x|^q`。文献指出 FLOM 类方法的
> "limitless mapping output" 使其性能随 α 下降而恶化。
> GELCT 的对数映射比任何幂律都温和：`t=10⁹` 的脉冲只被压到 `|f|≈8.6`，
> 所以它**不继承** FLOM 的这个问题。这是论断没有看到的区别。

## 3. 论断中**确实成立**的部分

### 3.1 去掉式 (8) 的 LCT 确实崩溃 —— 这是论断的真正内核

`experiments/lct_vs_gelct.py`：**同一份变换代码、同一窗长/hop/FFT**，唯一差别是输入 `f[r]` 还是 `r`。
以真实瞬时频率 ±1.5 个频率格内的能量占比为"脊线聚集度"：

| α（GSNR = −5 dB） | LCT（原始信号，无式 8） | GELCT（f[r]） |
|---|---|---|
| 1.0 | **0.0052**（脊线被摧毁） | **0.1080**（21 倍） |
| 1.5 | 0.0435 | 0.1356（3 倍） |

图：`results/collapse_lct_vs_gelct.png`。文献也有明确记载：

> "The existing linear chirplet transform (LCT) **degenerates, even fails** under α stable
> distribution environment." — Long, Wang, Fan, Lao, *PLoS ONE*, 2022（提出 FLOLCT 来修复）

**所以可断言的是"未变换的 LCT 会崩溃"，而不是"GELCT 会崩溃"。GELCT 本身属于那篇文献所说的
"修复"家族（非线性变换 + chirplet），不是被修复的对象。**

### 3.2 GELCT 的最坏情况崩溃点确实是 0（C2）

因为 `|f[r]| = |1 + ln|r|/e|` 仍然无界，**一个**`|r| = e^{cN}` 量级的样本在原理上足以主导相干累加。
所以 GELCT **不是** Hurwicz–Tukey 意义上的稳健估计量（不是 redescending 型），
它的崩溃点严格等于 0。**这一点不能在论文里含糊过去。**

值得注意的是概率量级：要让单样本压过信号的相干贡献 `N·A`，需要
`|r| ≳ exp(e N A)`；本配置（N=1024, A≈0.5）下是 `exp(1390)` 量级，
概率约 `e^{-α·1390}` —— **指数小**。而 LS 只需 `|r| ≳ N·A ≈ 512`，概率约 `512^{-α}` —— **幂律**。
两者都"崩溃点=0"，但一个的失效概率随 N 指数衰减、另一个只按幂律衰减。这是可断言、可量化的差别。

### 3.3 GSNR ≤ −15 dB 时 GELCT 也会失效

见下表 −15/−20 dB 两行。所以"GELCT 永不崩溃"也是**错的**——它有一个阈值，只是比 LS 低 15–20 dB。

## 4. 受控实验：单变量操纵

`experiments/collapse_test.py`（150 次蒙特卡洛/格点，α ∈ {0.8,1.0,1.2,1.5,2.0}，GSNR ∈ [−20,10] dB）：

**设计要点**：两条流程**代码完全相同**（同搜索栅格、同目标函数、同数据、同种子）——
LS 作用在 `r` 上，GELCT 作用在 `f[r]` 上。因此任何性能差异**只能**归因于式 (8)。
这样也自动排除了"GELCT 只是搜索范围更小/运气更好"的替代解释。

### 4.2 NRMSE(k)（式 52，dB）

| GSNR | α=1.0 LS / GELCT | α=1.5 LS / GELCT | α=2.0 LS / GELCT |
|---|---|---|---|
| −10 | +10.2 / **−49.4** | +8.8 / **−62.1** | −49.8 / −55.1 |

### 4.3 三条读数

1. **LS 不是"在某个阈值以下崩溃"，而是"在 α 较小时从不工作"**：
   α=0.8 时即使 GSNR = +10 dB 仍有 **90%** 严重失效；α=1.0 时 24.7%。
   它的 NRMSE 停在 **+9 ~ +10 dB**（误差大于参数本身）。
2. **GELCT 在所有 α（含 α=0.8）从 −10 dB 起失效率为 0%**，中位相对误差 `1.3×10⁻⁴ ~ 6.4×10⁻⁴`。
3. **两者的失效阈值相差 ≥ 15–20 dB，且在低 α 时差距发散**（LS 永不恢复）。
   所以"GELCT 和 LS 一样会 collapse"与数据方向相反。

图：`results/collapse.png`（三面板：误差、失效率、以及"最大样本经式 (8) 后被压到多大"——
最后一栏显示 `max|r|` 从 10²~10³ 被压到 **3.5 左右**，这就是机制本身）。

## 5. 可以断言的四条替代表述（建议直接替换原句）

> **R1（可断言）** 未施加非线性变换的线性 chirplet 变换（LCT）在 SαS 杂波中会退化甚至失效——
> 其时频脊线聚集度在 α=1、GSNR=−5 dB 时仅 0.005，与 LS 等二阶统计量方法同源而共命运。
>
> **R2（可断言）** GELCT 的对数幅度变换（式 8）把 α<2 时无界的二阶矩化为有限矩，
> 从而**阻断**了 LS 式崩溃的机制；这有解析证明（`ln|X|` 的指数尾）与数值验证（见 §2）。
>
> **R3（可断言，且是应该写进论文的自我批评）** GELCT 的崩溃点仍为 0：
> 式 (8) 的映射虽为对数但有界性并不成立，单个 `e^{O(N)}` 量级的样本原则上仍可主导估计。
> 其优势是**概率性**的（失效概率随样本数指数衰减，而 LS 仅幂律衰减）与**矩性**的（有限 vs 无穷）。
>
> **R4（可断言）** GELCT 存在一个低信噪比失效阈值：本配置下 GSNR ≤ −15 dB 时失效率升至 9%–41%，
> ≤ −20 dB 时完全失效。该阈值比 LS 低 15–20 dB 以上，但**并非不存在**。
>
> **R5（有条件可断言）** 若把"LS"限定为某种**特定**实现（例如搜索域被严格限制、
> 或噪声分散系数被归一化到不同尺度），或把 α 限定在 α ≈ 2 附近，则"两者相近"可能成立。
> 但这已经不是原论断。

## 6. 本评估自身的局限（不掩盖）

1. 只测了**单分量** LFM；论文第 VI 节还声称对多分量有效，未检验。
2. 噪声按式 (34) 取**实**象限（γ = 1，由 `A=√(10^{GSNR/10})` 设 GSNR）。
   复噪声下二者都会更差约 3 dB，**不改变序关系**，但绝对阈值会移动。
3. 未包含 DSSS 有用信号 `x(t)`（为与 CRLB 的推导前提式 (34) 对齐）；加入后 LS 会更差。
4. α 只测到 0.8（α<0.5 时 SαS 密度在 0 附近的行为与 GSNR 定义都会变得微妙）。
5. 单一蒙特卡洛活动（150 次/格点）。鉴于 SαS 的重尾性，跨活动的方差不可忽略；
   表中 ±3% 量级的差异不应被解读。**序关系（LS 失效 vs GELCT 不失效）在 7 个 GSNR × 5 个 α
   共 35 个格点上一致**，这不是偶然。
6. 式 (8) 在 `|r| < e^{-e} ≈ 0.066` 时增益为负（相位翻转 π）。本实验的 GSNR ≥ −20 dB 时
   `A ≥ 0.1`，部分落在该区间附近，但未做专门的压力测试。**这是该变换一个真实的设计脆弱点，
   值得单独立题。**

## 7. 总体判断

| 判据 | 结论 |
|---|---|
| 论断强度与证据是否匹配 | **否**——论断为强断言（"一样会"），证据方向相反 |
| 是否存在逻辑跳跃 | **是**——把"未变换的 LCT 失效"外推为"GELCT 失效"，忽略式 (8) |
| 是否存在机制层面的错误 | **是**——式 (8) 的存在使 C1 型崩溃在数学上不可能 |
| 是否有部分成立 | **是**——C2 型（崩溃点=0）与 C3 型（GSNR≤−15 dB）成立，见 §3.2/§3.3 |
| 建议处理 | 不要按原样断言。改用 R1–R4 中对应审稿立场的那一条 |

**如果目标是提出建设性批评**，最有价值、也最站得住的立论不是"GELCT 会崩溃"，
而是 **§3.2 的崩溃点问题**（GELCT 不是稳健估计量，只是"重尾友好"）以及
**§6.6 的负增益区问题**（`|r| < e^{-e}` 的相位翻转）。这两条是新发现，且无法被原论文的仿真反驳。
