# GELCT — 广义扩展线性 chirplet 变换（含 LFM 干扰参数估计）

对以下文献的实现：

> Mingqian Liu, Yuting Han, Yunfei Chen, Hao Song, Zhutian Yang, Fengkui Gong,
> **"Modulation Parameter Estimation of LFM Interference for Direct Sequence Spread
> Spectrum Communication System in Alpha-Stable Noise"**,
> *IEEE Systems Journal*, vol. 15, no. 1, pp. 881–892, March 2021.
> DOI: 10.1109/JSYST.2020.2991078

论文解决的问题：DSSS 通信系统中，LFM（线性调频）宽带干扰叠加在 α 稳定分布（SαS）脉冲噪声
之上。由于 SαS 噪声没有有限的二阶矩，传统二阶统计量失效。论文提出

1. **非线性变换**（式 8）压缩脉冲幅度、保留相位；
2. **GELCT（广义扩展线性 chirplet 变换，式 7）** 抑制 SαS 噪声并获得聚焦的时频图；
3. **Radon 变换**（式 9–14）在时频图上检测脊线 → 估计调频斜率 `k`；
4. **广义 Fourier 变换 GFT**（式 15–20）解线调后估计起始频率 `f0`；
5. 推导了 `k`、`f0` 的 **CRLB**（式 44–51）并给出估计量渐近性质。

## 3. 关键实现要点

### 3.1 非线性变换（式 8）

`f[r] = (log_e(|r|^{1/e}) + 1)/|r| · r = [ln|r|/e + 1] · r/|r|`
（**e 为自然常数**，`log_e` 为自然对数）

增益 `g(|r|) = ln|r|/e + 1` 只与幅度有关，**相位完全不变**——这正是 Property 1 的内容，
也是后文 GFT 能与解线调因子交换的原因。

实测幅度压缩效果（`smoke_test.py`）：

| `|r|` | 1e−4 | 1e−2 | 1e0 | 1e3 | 1e6 | 1e9 |
|---|---|---|---|---|---|---|---|
| `|f[r]|` | 2.39 | 0.69 | 1.00 | 3.54 | 6.08 | 8.62 |

即把 13 个数量级的动态范围压缩到约 `[0.7, 8.6]`，单个巨大脉冲不再淹没整个相干积分。

> **注意**（按式 8 字面实现的必然结果）：增益 `g(|r|)=1+ln|r|/e` 在
> `|r| < e^{-e} ≈ 0.066` 时为负，此时输出相位翻转 π。`smoke_test.py` 里能看到
> `|r|=1e-2` 的"相位误差"为 π。也就是说该变换对极弱样本做的是"符号化 + 对数压缩"，
> 而不是保号压缩。论文未讨论这一区间，本实现保持与论文公式一致，不做额外修正。

### 3.2 GELCT（式 7）中 θ 的作用

把式 (7) 的核 `h(τ−t)·exp(−j½(τ−t)²c(θ))` 代入积分，对被积相位做驻定相位分析可得：

* 脊线位置恒为 `ω(t) = 2πf0 + 2πkt`，**与 θ 无关**；
* 窗内残余二次相位为 `(2πk − c(θ))(τ−t)²/2`，当 `c(θ) = 2πk` 时**恰好消失**，脊线最锐利。

所以 θ 的物理作用不是"移动脊线"而是"聚焦脊线"。代码据此实现"扩展"二字：对每一帧在
`θ_l = −π/2 + lπ/(L+1), l=1..L` 中挑选使谱聚集度（峰值能量/总能量）最大的那个 θ。
这等价于逐帧自适应本地调频率，把普通 STFT 的模糊脊线变成锐利直线。

### 3.3 Radon 的数值稳健化（两处必须处理的问题）

**问题一：退化方向。** 直接按式 (12) 在 (角度 v, 偏移 u) 上离散时，`v→0` 的直线沿整条
时间列积分，噪声底噪"整列求和"必然取胜，脊线被淹没（实测 GSNR=−5 dB 时估计完全发散）。

**问题二：斜率方向的梳状旁瓣。** 脊线越锐利，Radon 目标函数沿斜率方向越呈现梳状振荡，
齿间距约 `Δf/T_span`（本配置 ≈1.7%）。若粗搜索步长与该间距同量级，就会"锁错齿"，
表现为高信噪比下约 1.9% 的误差平台。

代码的处理：

1. `preprocess_tf`：**频率白化**——把每个频率行除以它的时间均值，压平噪声底噪，
   退化方向消失；再取幂次 `|G|^p`。实测 `p` 是关键：`p=2` 时高信噪比有 1.9% 平台，
   `p=4`（默认）时降到 ~1e-3。
2. `radon_projection`：把同一条直线改用 **(斜率, 截距)** 参数化，
   `R(k,f0) = Σ_t A(t, f0 + k t)`。此时每条候选直线积分相同多的样本，且与式 (14) 的
   `−cot(v̂)` 一一对应（`slope_bins = −cot(v̂)`）。
3. 三级栅格（粗 → 中 → 细）+ 抛物线亚栅格插值。另外提供 `k_hint` 参数，可用全窗结果
   （3.4 节）把粗搜索限制在 ±25% 内，进一步避免锁错齿。

### 3.4 全窗极限（本实现额外提供的加速/高精度通道）

由 3.1 的相位保持性，`f[r·e^{−jπkt²}] = f[r]·e^{−jπkt²}`。于是当式 (7) 的窗长取满记录
（`win_len = N`，只剩一帧）时，GELCT 的 Radon 变换退化为对 `k` 的一维相干扫描：

```
k̂ = argmax_k  max_w |FFT( f[r] · e^{−jπkt²} )|
```

它把全部 N 个样本做相干积累（没有短窗损失），因此精度远高于短时平面
（见下面结果）。代码中为 `estimate_k_full_window` / `coherent_dechirp_scan`。

## 4. 运行方式


`fs = 10240 Hz`，`Ts = 0.1 s`。噪声按式 (6) 的约定生成：`γ = 1`，由信号幅度
`A = sqrt(10^(GSNR/10))` 设定广义信噪比。

## 5. 结果

（全部由上面的脚本生成，原始数据在 `results/*.npy`、日志在 `results/*_log.txt`）

### 5.1 GELCT 确实让脊线聚焦

在 α=1.5、GSNR=−5 dB 的一次实现中，以真实瞬时频率 ±1.5 个频率格为带，计算带内能量占比
（"脊线聚集度"）：

| 普通 STFT of f[r] | GELCT (式7) |
|---|---|
| 0.081 | **0.127**（+55%） |

即逐帧自适应 θ 的 chirplet 核把模糊脊线显著锐化。

### 5.2 单次估计（`demo_single.py`，α=1.5，GSNR=−5 dB）

| | 真值 | 估计 | 相对误差 |
|---|---|---|---|
| 调频斜率 k（GELCT+Radon，式7/12/14） | 10000 Hz/s | 10006.6 | 6.6×10⁻⁴ |
| 起始频率 f₀（GFT，式16/20） | 1000 Hz | 999.95 | 4.6×10⁻⁵ |
| k（全窗通道，3.4 节） | 10000 Hz/s | 10001.7 | 1.7×10⁻⁴ |

### 5.3 NRMSE vs GSNR（`demo_nrmse.py`，150 次蒙特卡洛/点，式52）

NRMSE 的**中位数相对误差**（括号内为相对误差 <3% 的命中率）：

| α | GSNR | GELCT+Radon（短时） | GELCT 全窗 | CRLB(k) |
|---|---|---|---|---|
| 1.0 | −8 dB | 3.2×10⁻³ (97%) | 6.0×10⁻⁴ (100%) | −182.5 dB |
| 1.0 | −5 dB | ~1.8×10⁻³ (100%) | ~4.3×10⁻⁴ (100%) | −185.5 dB |
| 1.0 | −10 dB | 1.5×10⁻² (79%) | 7.7×10⁻⁴ (100%) | −180.5 dB |
| 1.5 | −8 dB | 1.7×10⁻³ (99%) | 4.5×10⁻⁴ (100%) | −181.8 dB |
| 1.5 | −10 dB | 4.0×10⁻³ (96%) | 5.4×10⁻⁴ (100%) | −179.8 dB |
| 2.0 | −8 dB | 1.7×10⁻³ (100%) | 3.8×10⁻⁴ (100%) | −182.5 dB |
| 2.0 | −12 dB | 1.3×10⁻² (81%) | 6.1×10⁻⁴ (100%) | −178.5 dB |

结论与论文图 1/2 一致：

* 短时 GELCT+Radon 在 GSNR ≳ −8 dB 时把 k 的相对误差压到 `10⁻³` 量级、f₀ 压到 `10⁻⁴`
   量级，与论文报告的 `0.2×10⁻²`（k）同量级；
* GSNR ≤ −10 dB 时短时通道开始出现离群（命中率掉到 80%），而**全窗通道到 −12 dB 仍保持
   100% 命中、误差 `10⁻⁴` 量级**；
* 两条曲线都随 GSNR 单调下降，与 CRLB 趋势一致（CRLB 本身在 `10⁻¹⁰` 量级，是理想相干
   估计的渐近下界，短时平面受时频分辨率限制无法接近——论文自身也没有真正触到 CRLB）。

## 6. 实现说明与与论文的差异（诚实记录）

1. **Radon 的参数化**。论文写的是 `(u,v)` 角度形式；本实现改用等价的 `(k,f0)` 斜率-截距
   形式，原因是离散化后角度形式在低信噪比下会被退化方向劫持（3.3 节）。`v̂` 仍会给出，
   并严格满足 `k̂ = −cot(v̂)Δf/Δt`。
2. **预处理幂次 p**。`|G|^p` 的 p 是决定性的：p=2 时高信噪比存在约 1.9% 的"锁错梳齿"
   平台，p=4（默认）降到 `10⁻³`。见 3.3 节。
3. **窗长**。论文未给出 `win_len`。本实现默认 `win_len = 256`、`hop = 8`。短时平面的
   调频率分辨率约为 `Δf/T_span`，这与论文图 1/2 中 `~0.2×10⁻²` 的量级一致；
   需要更高精度/更低信噪比时请使用全窗通道（3.4 节），可到 `10⁻⁴` 量级。
4. **短时 Radon 的误差是重尾的**。由于 SαS 噪声本身的极端重尾性，短时通道偶尔会出现
   "差一个梳齿"（≈1.7%）的结果——150 次蒙特卡洛的中位数很好（`10⁻³`），但单次实现
   可能是尾部样本。全窗通道没有这个问题（所有测试种子都在 `10⁻³` 以内）。
5. **噪声象限**。式 (34) 把 `e(nTs)` 作为单个标量加到复信号上（实噪声），而式 (35) 又对
   实部、虚部分别写似然（等效复噪声）。代码 `quadrature` 参数同时支持 `'real'`（默认，
   与式 34 字面一致）和 `'complex'`。复噪声情形下性能约差 3 dB 左右。
6. **CRLB 与实测的差距**。CRLB（式 44/45）在 0 dB 处给出 `std(k)/k ≈ 3×10⁻¹⁰` 量级，
   是理想相干估计的理论下界；短时平面估计受时频分辨率限制无法接近，差距属正常现象。
   本实现**未复现**论文图 4/5 中的 Sigmoid-FPSD、FLOSAT 对比算法，只对比 CRLB。
7. **κ(α)**。论文式 (49) 写作 `κ(2)=2`，但这与式 (50) 的系数 `6/(4κ)=3` 矛盾
   （`⇒ κ=0.5`）。本实现用数值积分 `∫(f')²/f dx` 得到 `κ(1)=0.5`、`κ(2)=0.5`，
   与式 (46)、(50) 自洽。`κ(α)` 由 `kappa_alpha` 现算。

## 8. CRLB 单位修正（2026-11-02）

早期 `crlb_*` 调用把 `Ts` 取成 0.1 s（CPI），正确应为**采样间隔** `Ts=1/fs`。
按 `Ts=1/fs`，N=1024、fs=10240、0 dB 时 `std(k)≈3.1 Hz/s`、`std(f0)≈0.12 Hz`，
与论文的 `crlb_lfm` 一致（real/complex，~3–4×）。因此：

- §5.3 的 “CRLB −182 dB” 应约为 **−70 dB**；
- GELCT 的相对误差 ~10⁻³ 与 CRLB ~3×10⁻⁴ **同量级**，GELCT **并非**远离 CRLB；
- 论文中 “GELCT not CRLB-competitive” 已据此改为 **“GELCT alone is CRLB-competitive (0.03–0.67×)”**；
- `demos/` 与 `smoke_test.py` 已把 `crlb_*` 的 `ts` 改为 `1/fs`；`nrmse.png`/`alpha.png` 的 CRLB 线仍是旧图，重跑后更新。
