## 2. 变量规范（每个 .mat 通用）

| 变量 | 维度 / 类型 | 含义 |
|---|---|---|
| `pc` | 脉冲×距离单元，**complex64** | 距离-慢时间复数据（已脉压）。2025 取厂商 IQ；2019/2020/2022 取官方 MAT 的 T2 |
| `if_raw` | 脉冲×1760，int16 | **仅 2025 的 6 个文件**：脉压前中频实信号（60 MHz、14 bit），供去斜/匹配滤波 |
| `range_m` | 1×单元，double | 距离单元中心（m） |
| `t_s` | 1×脉冲，double | 相对首脉冲的时间（s） |
| `az_deg` | 1×脉冲，double | 天线指向方位角（°，含方位修正；凝视数据为常数，圆心为负值） |
| `trig` | 1×脉冲，uint32 | 触发脉冲计数（IF/IQ 对齐与去重用） |
| `tgt_bin` | 1×脉冲，uint16 | 该脉冲上目标所在距离单元（1-based，0=该脉冲无目标）。仅 2025 |
| `tgt_range_m` / `tgt_az_deg` | 1×脉冲，single | 该脉冲上目标的距离/方位（2025 来自 CutDataTarget） |
| `clutter_cells` | 1×N，uint16 | **纯杂波单元**（已剔除目标±2、强散射体±2、首尾 5 单元），1-based |
| `target_cells` | 1×N，uint16 | 目标占据的距离单元（2025 由目标外接矩形换算；其余期为 0×0） |
| `strong_cells` | 1×N，uint16 | 数据驱动的强散射体（岸线/建筑/浮标），1-based |
| `land_sectors_deg` | N×2，double | 高功率方位扇区（多为陆地/港口），圆扫数据才有 |
| `grazing_deg` | 1×单元，double | 掠射角（°，按架高 + 4/3 地球模型；**2019/2020 架高未知 → NaN**） |
| `meta` | struct（44 字段） | 数据集名/期次/极化/模式/PRF/采样/波形(脉宽·带宽·k·TBP·分辨率)/海况/波高/风向/温度/目标船名·MMSI·船型·距离/架高/处理链标注 |
| `info` | 脉冲×K，double | 仅 2019/2020（K=48）与 2022（K=26）：原始数据头矩阵，列定义见 `_inventory` 报告与说明 PDF |
| `notes` | char | 一句话说明 |

典型用法（MATLAB）：
```matlab
S = load('MTDSP2025_HH_413020540.mat');
x = S.pc(:, S.clutter_cells(1));   % 某杂波单元的慢时间序列
r = S.range_m(S.clutter_cells);    % 这些单元的距离
```

## 3. 距离单元怎么用（对应你的四步）

| Step | 用什么 | 说明 |
|---|---|---|
| 0 数据接入 | `meta` + `range_m`/`az_deg`/`t_s` | 每脉冲点数、采样率、PRF、极化、模式、海况都在 `meta` |
| 1 去斜/解调 | `if_raw` + `meta.fs_mhz`、`chirp_rate_hz_s`（k=3.12e12）、f₀≈15 MHz | 演示见 `demo_step1_step2.m`；输出可对照 `pc` |
| 2 杂波刻画 | `pc` + `clutter_cells` + `az_deg` | 按 5° 方位带跨转数池化；圆扫先用 `land_sectors_deg` 剔岸线 |
| 3 参数估计 | `pc` + `clutter_cells` + `tgt_bin` | 注入时用 `tgt_bin≠该单元` 的脉冲，保证注入点是纯杂波 |
| 4 两径多径 | `grazing_deg` + `range_m` + `meta.radar_height_m` | 2019/2020 的掠射角需先补架高再算 |

## 4. 已跑通的结果

### Step 1 去斜 + Range-Doppler
`_verify\step1_rd.png`：`MTDSP2025_HH_413020540` 前 3000 脉冲，k=3.12e12 去斜后取 30~35° 方位带做慢时间 FFT。
去斜距离剖面出现若干离散强峰；Range-Doppler 在相对距离 ≈+100 m 处有一条零多普勒亮带（固定强散射体），海杂波集中在 ±50 Hz。

### Step 2 逐单元 α
`_verify\step2_alpha.png` / `step2_alpha.csv`：三组 HH/VV 配对、同方位带、固定 5°、n≈5000~10000 脉冲/单元。

| 配对（2025） | 方位带 | HH α 中位 | VV α 中位 |
|---|---|---|---|
| 413020540（海况2，拖轮） | 49~54° | 2.00 | 1.94~1.98 |
| 412331720（海况3，货船） | 14~19° | 1.96 | 1.77~1.88 |
| pure（海况3，无指定目标） | 15~20° | 1.71~1.83 | 1.29~1.44 |

规律：**HH 稳定在 1.9~2.0，VV 明显更低且随距离下降**（3 km ≈1.7 → 6 km ≈1.0~1.2），与“VV 纹理更强、更非高斯”一致。
注意：α 的绝对值强烈依赖方位带与池化口径（单视/短驻留会给到 2.0），跨期比较必须固定口径。

### Step 3 注入弱 LFM 的参数估计（LS / Huber / SαS-MLE）
慢时间注入：N=256 脉冲、f₀∈[0.1,0.3]·PRF、k=625 Hz/s、A 由每样本 SNR 定。CRLB 用 (f₀,k,φ) 三参数 FIM 的 Schur 补
（只用 (f₀,k) 两参数会低估约 1.6 倍）。

| 场景 | −2 dB | +2 dB | +6 dB | +10 dB |
|---|---|---|---|---|
| 高斯 CRLB（Hz） | 0.96 | 0.60 | 0.38 | 0.24 |
| 复高斯 LS（实现对照） | 0.87 | 0.87 | 0.53 | 0.39 |
| 合成 α=1.9 LS | 0.99 | 0.72 | 0.56 | 0.30 |
| 合成 α=1.6 LS → Huber/MLE | 2.37 | 2.12 → **0.61/0.57** | 0.60 | 0.62 → 0.29/0.30 |
| 合成 α=1.3 LS → Huber/MLE | 230 | 17.8 → 15.7/17.7 | 1.59 | 1.24 → **0.45/0.42** |
| 真实 HH（α=1.70）RMSE / MAD | 258 / 129 | **79.1 / 0.24** | 0.26 / 0.13 | 0.18 / 0.09 |

三条结论：① 白噪声下三估计器都 ≈1.2~1.6×CRLB（实现正确）；② α=1.6 时稳健估计把 +2 dB 的误差从 2.12 Hz 压到 0.61 Hz（3.5×），
但 α=1.3 在阈值区三者同等失败、到 +10 dB 仍是 2~5×CRLB（CRLB 不可达）；③ 真实杂波里 HH 在 +2 dB 的 **RMSE 79 Hz 而 MAD 0.24 Hz**，
且 LS/Huber/MLE 给出同一个数——失败来自少数杂波块的“整块失配”，稳健损失无效，这正是 Step 4 要显式建模的 bias floor。

## 6. 已知限制

1. **脉冲数上限**：两个 `_pure` 文件各取前 80000 脉冲（原始 12.6 万），2022 取前 20000（原始 13.1 万），其余为全量；`meta.n_pulses_total` 记原值。
2. **2025 的 `pc` 是厂商 IQ**（已脉压、含厂商加窗与可能的补偿）；要跑“自己的脉压/去斜”请用 `if_raw`。
3. **2019/2020/2022 没有逐帧目标表**，`target_cells` 为空；请用 `strong_cells` 与 `land_sectors_deg` 规避强散射体，或用 AIS 自行标注。
4. **2022 的距离步长 6 m 是推断值**（T2 起始 1.17 km + 25 MHz 抽取），`meta.range_step_note` 有记录，用前建议用浮标/AIS 校核。
5. **雷达架高**：2022/2025 取 80 m（2023 论文，同一试验点）；2019/2020 无官方值，`grazing_deg` 为 NaN。
6. `_pure` 表示“无指定合作目标”，但视场内仍有 AIS 船舶与岸线，**不是纯净海面**。
7. Step3 的真实杂波是**有色**的（谱在 DC −10.6 dB、±500 Hz −36 dB），高斯 CRLB 只是白噪声量级参考；合成部分每个 SNR 仅 40 次试验，个别点受野值影响不单调。
